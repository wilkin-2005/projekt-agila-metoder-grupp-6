# Sprint Review

## 🎯 Sprint Goal

### Vårat Sprint Goal (från uppgiftsbeskrivningen)

Planering, setup och första kodbasen. Skapa listsidan (men ingen fungerande filtrering, sök, paginering osv). Om ni vill får ni gärna göra de olika formulärsidorna (skapa/redigera produkt), men utan funktionalitet då vi kommer titta på det mer senare.

## ✅ Funktioner vi visade

- Headern
- Tabellen som visar upp produkterna från API:t.
- "Stock status overview"-sektionen blev praktiskt taget klar. Den behöver bara mergeas in i `main`.

## 🌟 Vad blev bättre än väntat?

- Vi sammarbetade och arbetade bättre tillsammans än förväntat.
- Det gick bättre än förväntat att dela ut och göra de uppgifter man valde.

## ⏳ Vad hann vi inte?

- Sök- och filter-sektionen vet vi inte om den är klar. Den ligger som klar på Github Projects men finns inte med i `main`.
- "Stock status overview"-sektionen har inte hunnit mergeas in i `main` ännu.

## 📋 Behöver Product Backlog uppdateras?

- Product Backlog skulle behöva uppdateras med mer detaljerade beskrivningar och instruktioner m.m.

# 🔄 Sprint Retrospective

## 😊 Det här fungerade bra

- Github Projects
- Git
- Arbetsfördelning

## 🤔 Det här fungerade mindre bra

- Otydliga Issues som helt saknar beskrivningar.
- För stora branches/Pull Request som var svåra att läsa igenom.
- Filter-sektionen har vi missat helt. Ligger på Done i GH Projects men finns inte med i `main`.

## 🚀 Två förbättringar till nästa sprint

1. Skriva tydligare och mer detaljerade Issues.

2. Vara noggrannare med att hålla oss till vårt Sprint Goal.

# ❤️ Kom ihåg

En sprint behöver **inte vara perfekt**.

Det viktiga är att ni lär er något.

> **Bra Scrum-team blir inte bättre för att de aldrig gör misstag.**
>
> **De blir bättre för att de lär sig av dem. 🚀**
